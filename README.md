# LifeShelf releases

Official signed Android builds for [LifeShelf](https://github.com/AbhinavChemikala/LifeShelf), a personal archive for files, notes, documents, cards, and contacts.

Download the newest APK below. Choose the universal package if you are unsure which device variant to use; otherwise choose the `arm64-v8a`, `armeabi-v7a`, or `x86_64` package for your device. Each release includes a changelog and SHA-256 checksums.

The app can also check this repository for updates from **Settings → Check for updates**. It shows the release notes and asks before downloading; Android's package installer confirms before installation.

Only install LifeShelf APKs you trust. Updates must be signed with the same Android release key as the installed app.
